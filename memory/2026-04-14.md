## Facebook Monitor Project

Drew asked me to set up a Facebook profile monitoring system to check for new posts hourly.

### Target
- **URL:** https://www.facebook.com/erica.pullens.2025 (Erica Pullens)
- **Profile:** Public, visible in incognito/headless browser

### Technical Details
- Facebook blocks all non-browser requests (web_fetch, curl both fail)
- **Playwright headless Chromium works** on this droplet for public Facebook profiles
- Had to install playwright locally + system deps were already present (libatk etc.)
- Posts extracted via text pattern matching (relative timestamps like "3d", "1h")

### What Was Built
- **Directory:** `workspace/facebook-monitor/`
- `monitor.js` — Playwright script, extracts posts, diffs against state.json, outputs JSON
- `config.json` — profiles to monitor (extensible, can add more)
- `state.json` — stores fingerprints + post data for change detection
- Baseline captured: 2 posts visible (shared post about heart's nervous system)

### Cron Job
- **Job ID:** `01b4be05-e8de-4626-a94c-4debb637b80d`
- **Schedule:** Every hour
- **Session:** Isolated agent turn
- **Delivery:** none (agent DMs Drew on Discord only when new posts found)

### Notes
- Drew wants Discord DM notifications for new posts
- First run was baseline capture (no alerts)
- System is extensible — add more profiles to config.json
